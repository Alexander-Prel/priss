# ML-система мониторинга пользовательских реакций

Система автоматически классифицирует комментарии социальной сети по тональности и риску модерации. Она выявляет негатив, токсичность, запрещенный контент и спам, маршрутизирует спорные случаи модераторам и сохраняет решения для аудита и последующего переобучения модели.
