# Бизнес-процесс до внедрения ML-системы

[Вернуться к мастер-документу](../docs/MLSD_Master_Document.md)

```mermaid
flowchart TD
    A[Пользователь оставляет комментарий] --> B[Комментарий попадает в общий поток]
    B --> C[Модератор выборочно читает комментарии]
    C --> D{Комментарий проверен?}
    D -->|Да| E[Модератор принимает решение]
    D -->|Нет| F[Часть негатива и нарушений пропускается]
    E --> G[Реакция запаздывает]
    F --> G
    G --> H[Бизнес получает репутационные и регуляторные риски]
```

Основные проблемы процесса:

- проверяется только часть потока;
- качество зависит от опыта и загрузки модератора;
- нарушения обнаруживаются с задержкой;
- решения и причины решений не всегда доступны для аудита.
